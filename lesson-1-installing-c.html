🛠️ Setting Up C on Your Computer

Before we can write programs in C, we need two tools: a compiler and a text editor. This lesson installs both on a Windows computer.
In this lesson
  1. What do we need?
  2. Install the GCC compiler (MinGW-w64)
  3. Add GCC to PATH
  4. Check that it works
  5. Install Sublime Text
  6. Save your first C file

1. What do we need?

Computers don't understand C directly. They only run machine code. A compiler is a program that translates your C code into a program the computer can run (an .exe file on Windows).

hello.cYour C code
(you type this)
→
gccThe compiler
(translates it)
→
hello.exeA program
you can run

We'll use GCC (the GNU C Compiler). On Windows, GCC comes in a package called MinGW-w64 ("Minimalist GNU for Windows"). For typing our code we'll use Sublime Text, a fast and clean text editor.

2. Install the GCC compiler (MinGW-w64)

We'll use the WinLibs build of MinGW-w64. There's no installer, just a zip file you extract. That makes it easy to set up on school computers.

  1. Open your browser and go to winlibs.com.
  2. Scroll down to Download → Release versions → UCRT runtime.
  3. Under the newest GCC version (the first one in the list), find Win64 and click Zip archive. Choose the one without LLVM/Clang/LLD/LLDB, because it's a smaller download.
  4. When the download finishes, open your Downloads folder. Right-click the zip file → Extract All…
  5. In the box that asks where to extract, type C:\ and click Extract. (This may take a minute.)
  6. Open This PC → Local Disk (C:). You should now see a folder named mingw64.

Your folders should look like this:

C:\ └── mingw64 ├── bin ← gcc.exe lives here! │ ├── gcc.exe │ ├── g++.exe │ └── ... ├── include └── lib
⚠️ Check the folder! Make sure the file is at exactly C:\mingw64\bin\gcc.exe. Sometimes Windows makes an extra folder, like C:\winlibs-x86_64...\mingw64. If that happens, move the mingw64 folder so it sits directly inside C:\.
💡 Other ways to get MinGW You may also see MSYS2 or the old MinGW Installation Manager (mingw-get) online. They work too, but your gcc folder will be somewhere else, for example C:\msys64\ucrt64\bin or C:\MinGW\bin. Whatever folder holds gcc.exe is the one you add to PATH in the next step.

3. Add GCC to PATH

Right now, gcc is on your computer, but the Command Prompt doesn't know where it is. PATH is a list of folders Windows searches when you type a command. We'll add C:\mingw64\bin to that list.

  1. Click Start (or press the ⊞ Win key) and type environment variables.
  2. Click Edit the system environment variables. A System Properties window opens.
  3. At the bottom, click the Environment Variables… button.
  4. In the top box (User variables), click Path once to select it, then click Edit…
  5. Click New and type: C:\mingw64\bin
  6. Click OK → OK → OK to close all three windows.

💡 User or System variables? User variables only work for the person who is logged in, but you don't need an administrator password. On a shared school computer, the teacher can add it under System variables → Path instead, so it works for every account.
⚠️ Don't delete anything! Only add a new line. Never delete or change the lines that are already in Path, because other programs need them.

4. Check that it works

Open a new Command Prompt. Press ⊞ Win + R, type cmd, and press Enter. Then type this command and press Enter:

Command Prompt
C:\Users\Student> gcc --version
gcc (MinGW-W64 x86_64-ucrt-posix-seh, built by Brecht Sanders) 15.2.0
Copyright (C) 2025 Free Software Foundation, Inc.

🎉 If you see a version number like the one above, GCC is installed! (Your numbers may be different, and that's fine.)

What if it doesn't work?

Command Prompt
C:\Users\Student> gcc --version
'gcc' is not recognized as an internal or external command,
operable program or batch file.

This means Windows can't find gcc. Check these one by one:

  1. Close the Command Prompt and open a new one. A window that was already open before you changed PATH won't see the change.
  2. Check that C:\mingw64\bin\gcc.exe really exists (see the warning in Step 2).
  3. Go back to the PATH window and check the spelling: C:\mingw64\bin, with no extra spaces and bin at the end.
  4. Still stuck? Restart the computer and try again.

5. Install Sublime Text

  1. Go to sublimetext.com and click Download for Windows.
  2. Open the downloaded setup file and click Next → Next → Install → Finish.
  3. Open Sublime Text from the Start menu.
💡 About the pop-up Sublime Text is free to use. Once in a while it shows a small window asking you to buy a license. Just close it and keep working.

Can I use a different editor?

Yes! Any editor that saves plain text works. Here are a few options:

Sublime Text ⭐Fast, colorful, simple. Our class choice.
Notepad++Light and free. Good for older computers.
VS CodeFree and powerful, but it has more buttons to learn.
NotepadAlready on Windows. When saving, set Save as type to All files so you get hello.c, not hello.c.txt.

6. Save your first C file

  1. Make a folder for your programs: open This PC → Local Disk (C:), right-click → New → Folder, and name it cprog.
  2. In Sublime Text, click File → New File and type this program exactly:
hello.c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
  1. Press Ctrl + S, go to C:\cprog, and save it as hello.c.
  2. Once it's saved as .c, the words change color. That's Sublime recognizing it as C code! 🌈
💡 Why C:\cprog? A short folder name with no spaces is much easier to reach from the Command Prompt. You'll see why in Lesson 2!

In Lesson 2, we'll learn how to use the Command Prompt to go to this folder, compile hello.c with gcc, and run it.

⭐ Bonus: Build and run inside Sublime Text

Once you know the Command Prompt, you can let Sublime run gcc for you:

  1. In Sublime, click Tools → Build System → New Build System…
  2. Delete everything in the new tab and paste this:
C.sublime-build
{
    "shell_cmd": "gcc \"${file}\" -o \"${file_base_name}\"",
    "working_dir": "${file_path}",
    "selector": "source.c",
    "file_regex": "^(..[^:]*):([0-9]+):?([0-9]+)?:? (.*)$",
    "variants": [
        {
            "name": "Run",
            "shell_cmd": "gcc \"${file}\" -o \"${file_base_name}\" && start cmd /k \"${file_base_name}\""
        }
    ]
}
  1. Press Ctrl + S and save it as C.sublime-build (keep the folder Sublime suggests).
  2. Choose Tools → Build System → C.
  3. Open hello.c and press Ctrl + Shift + B, then pick C - Run. A Command Prompt window opens and shows your program's output!
