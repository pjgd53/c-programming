🔒 C Constants

Some values should never change, like the number of days in a week or the value of pi. A constant is a variable that is locked: read-only.

1. The const keyword

Put const in front of a variable to make it unchangeable:

example.c
#include <stdio.h>

int main() {
    const int DAYS_IN_WEEK = 7;
    printf("A week has %d days.\n", DAYS_IN_WEEK);
    return 0;
}
▶ Output
A week has 7 days.

If any part of your program tries to change it, gcc stops with an error:

example.c
#include <stdio.h>

int main() {
    const int DAYS_IN_WEEK = 7;
    DAYS_IN_WEEK = 8;
    return 0;
}
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:5:18: error: assignment of read-only variable 'DAYS_IN_WEEK'
    5 |     DAYS_IN_WEEK = 8;
      |                  ^

This protects you from changing important values by accident.

2. When should I use a constant?

Use const for any value that is fixed and should stay the same while the program runs:

snippet
const int MINUTES_PER_HOUR = 60;
const int MONTHS_IN_YEAR = 12;
const int PASSING_GRADE = 75;
const double PI = 3.14159265;
💡 Bonus: easy to updateIf the school changes the passing grade to 80, you change one line instead of hunting for every 75 in your program.

3. Constants must get a value right away

A const must be given its value when it is declared. You can't declare it first and assign the value later:

example.c
#include <stdio.h>

int main() {
    const int MINUTES_PER_HOUR;
    MINUTES_PER_HOUR = 60;
    return 0;
}
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:5:22: error: assignment of read-only variable 'MINUTES_PER_HOUR'
    5 |     MINUTES_PER_HOUR = 60;
      |                      ^
snippet
const int MINUTES_PER_HOUR = 60;   // correct: value given right away

4. Name constants in UPPERCASE

It's not required, but C programmers usually write constant names in ALL CAPS, with underscores between words. That way anyone reading the code knows instantly that the value is locked.

KindStyleExample
VariablecamelCase or snake_casestudentAge, total_score
ConstantUPPER_CASEMAX_STUDENTS, PI

5. const vs. #define

In Lesson 3 you saw #define in the Definition section. Both make constants, but they work differently:

Exampleconst double PI = 3.14159;#define PI 3.14159
Has a data type?✅ Yes (int, double…)❌ No, it just replaces text
Semicolon?✅ Yes❌ No

Today, many programmers prefer const because the compiler knows its type and can catch more mistakes. You'll see both in real code.

6. Real-life example: circle calculator

example.c
#include <stdio.h>

int main() {
    const double PI = 3.14159265;
    double radius = 7;

    double area = PI * radius * radius;
    double circumference = 2 * PI * radius;

    printf("Radius: %.1f cm\n", radius);
    printf("Area: %.2f sq cm\n", area);
    printf("Circumference: %.2f cm\n", circumference);
    return 0;
}
▶ Output
Radius: 7.0 cm
Area: 153.94 sq cm
Circumference: 43.98 cm

Passing or not?

example.c
#include <stdio.h>

int main() {
    const int PASSING_GRADE = 75;
    int myGrade = 82;

    printf("Passing grade: %d\n", PASSING_GRADE);
    printf("My grade: %d\n", myGrade);
    printf("Points above passing: %d\n", myGrade - PASSING_GRADE);
    return 0;
}
▶ Output
Passing grade: 75
My grade: 82
Points above passing: 7

7. Quiz 🎯

Try It! On a real computerWrite a program that uses constants for HOURS_PER_DAY (24), DAYS_PER_WEEK (7) and WEEKS_PER_YEAR (52). Calculate and print how many hours are in a week and how many days are in a year (52 weeks). Then try changing a constant later in the code, and read gcc's error.

✅ What You Learned

  • const makes a variable read-only. Changing it causes a compile error.
  • A constant must get its value when it is declared.
  • Use constants for fixed values: PI, DAYS_IN_WEEK, PASSING_GRADE.
  • Name constants in UPPER_CASE (a convention, not a rule).
  • #define PI 3.14 (no type, no =, no ;) is another way to make constants.
