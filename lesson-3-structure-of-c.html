🧱 Basic Structure of a C Program

A letter has a heading, greeting, body, and closing, always in that order. A C program also has parts (called sections) that must follow a set order. Let's learn what each part does.

1. The six sections

Every C program follows this basic structure, from top to bottom. A program doesn't need to use all six sections, but the ones it uses must stay in this order.

3. Each section explained

1️⃣ Documentation Section Optional, but a good habit

This section comes first. It holds comments: notes for people to read, such as what the program does, who wrote it, and when. The compiler ignores comments completely.

A comment can span many lines between /* and */, or take up one line starting with //.

Example
/* Program: Area of a Circle
   Author:  Juan Dela Cruz
   Date:    October 2026 */

// This is a one-line comment

2️⃣ Link Section Almost always needed

This section tells the compiler to link (connect) your program to header files. These are ready-made toolboxes of functions. Without stdio.h, your program won't know what printf means!

Example
#include <stdio.h>   // standard input/output: printf, scanf
#include <math.h>    // math functions: sqrt, pow

3️⃣ Definition Section Optional

This section defines constants: names for values that never change. #define tells the compiler: "Every time you see this name, replace it with this value."

Example
#define MAX 25         // every MAX becomes 25
#define PI  3.14159    // every PI becomes 3.14159

⚠️ No = sign and no semicolon at the end of a #define line!

4️⃣ Global Declaration Section Optional

Variables declared here, before main(), are global. That means every part of the program can use them: main() and all the other functions. Function prototypes (an announcement of a function that is written later) also go here.

Example
int timesUsed = 0;           // a global variable
float circleArea(float r);  // a function prototype

5️⃣ Main Function Section Required in every program!

main() is where the program starts running. Every C program must have exactly one main function. Its code goes inside curly braces { }, in two parts:

  • Declaration part: at the top, declare the variables you'll use and their data types (like int or float).
  • Executable part: the statements that actually do the work, such as calculating and printing.
Example
int main() {
    float radius, area;            // declaration part

    radius = 5.0;                   // executable part
    printf("Radius: %.1f\n", radius);
    return 0;                       // 0 means "finished OK"
}

🤔 void main() or int main()?

You may see void main() or just main() in older books and handouts. Here's the difference:

✅ int main() int means main gives back a number when it ends: return 0; tells Windows "I finished successfully." This is the official C standard and works with every compiler. Use this one!
⚠️ void main() void means "returns nothing," so the program never reports whether it worked. It's not standard C. Old compilers like Turbo C allowed it, but in C++ it's an error.

With -Wall, gcc warns you if you use void main():

Command Prompt
C:\cprog> gcc -Wall hello.c -o hello
hello.c:2:6: warning: return type of 'main' is not 'int' [-Wmain]
📘 Remember Your program's output looks the same either way. But good programmers build good habits, so always write int main() and end it with return 0;. A plain main() with nothing in front is the oldest style and also gets a warning today.

6️⃣ Subprogram (Function) Section Optional

Here you write your own functions: smaller programs that do one job and that main() can call (use) whenever it needs to. Breaking a big program into functions makes it easier to read, test, and fix.

Example
float circleArea(float r) {
    return PI * r * r;
}

4. Rules to remember

⬇️ Order mattersThe sections go top to bottom in the order 1 → 6. For example, you can't put #include after main().
🔤 C is case-sensitivemain, Main, and MAIN are three different words. Always type main and printf in lowercase.
; SemicolonsMost statements end with ;. Lines that start with # do not.
{ } Braces come in pairsEvery { needs a matching }. Indent the code inside so it's easy to see.

✅ What You Learned

  • A C program has 6 sections, always in this order: Documentation → Link → Definition → Global Declaration → Main → Subprogram.
  • Documentation = comments (/* */ or //), which the compiler ignores.
  • Link = #include header files. Definition = #define constants.
  • Global variables are declared before main() and can be used everywhere.
  • main() is required. It has a declaration part and an executable part.
  • Write int main() with return 0;, not void main().
  • Subprograms are your own functions, written after main().
