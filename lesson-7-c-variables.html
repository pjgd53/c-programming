📦 C Variables

A variable is like a labeled box that stores a value, such as a score, a price, or a letter. Your program can use or change what's inside later.

1. What is a variable?

Every variable has three things: a type (what kind of data it can hold), a name, and a value. The three basic types are:

TypeStoresExamples
intWhole numbers (no decimal point)13, -5, 2026
floatNumbers with decimals89.5, -3.75, 19.99
charOne single character, in single quotes'A', 'b', '7'

2. Creating (declaring) a variable

To create a variable, write its type, its name, and (optionally) = and a starting value:

syntax
type variableName = value;
snippet
int age = 13;
float average = 89.5;
char section = 'B';

The = sign here means "store this value in the box". It's called the assignment operator. It does not mean "equals" like in math.

You can also create the box first and put a value in later:

snippet
int score;      // declare: make an empty box named score
score = 95;     // assign: put 95 inside

3. Printing variables

You might expect printf(age); to print a variable, but in C it doesn't work:

example.c
#include <stdio.h>

int main() {
    int age = 13;
    printf(age);
    return 0;
}
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:5:12: error: passing argument 1 of 'printf' makes pointer from integer without a cast [-Werror=int-conversion]
    5 |     printf(age);
      |            ^~~

To print a variable, put a format specifier in the text where the value should appear, then list the variable after a comma:

SpecifierUsed for
%dint
%ffloat
%cchar
example.c
#include <stdio.h>

int main() {
    int age = 13;
    float average = 89.5;
    char section = 'B';

    printf("Age: %d\n", age);
    printf("Average: %f\n", average);
    printf("Section: %c\n", section);
    return 0;
}
▶ Output
Age: 13
Average: 89.500000
Section: B

You can mix text and several variables in one printf(). They fill in the specifiers in order:

example.c
#include <stdio.h>

int main() {
    int age = 13;
    char section = 'B';
    printf("I am %d years old and I am in section %c.\n", age, section);
    return 0;
}
▶ Output
I am 13 years old and I am in section B.
💡 Too many zeros?%f prints 6 decimal places (89.500000). Use %.1f for 1 decimal place or %.2f for 2. You'll practice this in Lesson 8.

4. Changing a variable's value

A variable can vary (that's where the name comes from!). Assigning a new value replaces the old one:

example.c
#include <stdio.h>

int main() {
    int score = 70;
    printf("Before: %d\n", score);

    score = 95;      // the old value 70 is replaced
    printf("After: %d\n", score);
    return 0;
}
▶ Output
Before: 70
After: 95

You can copy one variable's value into another, or use variables to calculate:

example.c
#include <stdio.h>

int main() {
    int math = 92;
    int science = 88;
    int total = math + science;
    int copy = total;

    printf("Total: %d\n", total);
    printf("Copy:  %d\n", copy);
    return 0;
}
▶ Output
Total: 180
Copy:  180

5. Declaring many variables at once

Several variables of the same type can be declared on one line, separated by commas:

example.c
#include <stdio.h>

int main() {
    int x = 5, y = 6, z = 50;
    printf("%d\n", x + y + z);
    return 0;
}
▶ Output
61

You can also give several variables the same value:

example.c
#include <stdio.h>

int main() {
    int a, b, c;
    a = b = c = 10;
    printf("%d %d %d\n", a, b, c);
    return 0;
}
▶ Output
10 10 10

6. Rules for naming variables

Variable names are called identifiers. They must follow these rules:

  • Use only letters, numbers, and the underscore _.
  • A name can't start with a number.
  • No spaces or symbols like -, ! or $.
  • Names are case-sensitive: score and Score are two different variables.
  • You can't use keywords (reserved words like int, return, float).
💡 Choose meaningful namesstudentAge is much clearer than x or sa. Two common styles: camelCase (studentAge) and snake_case (student_age).

7. Quiz 🎯

Try It! On a real computerWrite a program that creates variables for your age (int), your height in meters (float) and the first letter of your name (char). Print them in one sentence like: "I am 13 years old, 1.52 meters tall, and my name starts with J." Then change your age to next year's and print it again.

✅ What You Learned

  • A variable is a named box that stores a value.
  • Basic types: int (whole numbers), float (decimals), char (one character in single quotes).
  • Declare with type name = value;
  • Print variables with format specifiers: %d, %f, %c.
  • A new assignment replaces the old value.
  • Names: letters, numbers and _ only. They can't start with a number, can't contain spaces, and can't be keywords.
