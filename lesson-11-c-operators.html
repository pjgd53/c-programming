➕ C Operators

Operators are symbols that do things to values and variables: add, compare, combine and more. The values they work on are called operands.

1. What is an operator?

In 100 + 50, the + is the operator and 100 and 50 are the operands. Operators work with plain values, with variables, or with both:

example.c
#include <stdio.h>

int main() {
    int sum1 = 100 + 50;       // 150 (100 + 50)
    int sum2 = sum1 + 250;     // 400 (150 + 250)
    int sum3 = sum2 + sum2;    // 800 (400 + 400)

    printf("%d\n%d\n%d\n", sum1, sum2, sum3);
    return 0;
}
▶ Output
150
400
800

C groups operators into families. In this lesson we'll cover the first four:

  1. Arithmetic operators: math
  2. Assignment operators: storing values
  3. Comparison operators: comparing values
  4. Logical operators: combining true/false
  5. Bitwise operators: advanced, for later!

Division and modulus: the pizza example 🍕

You have 17 slices to share among 5 friends. Each friend gets 17 / 5 = 3 slices, and 17 % 5 = 2 slices are left over.

example.c
#include <stdio.h>

int main() {
    int slices = 17;
    int friends = 5;

    printf("Each friend gets: %d\n", slices / friends);
    printf("Left over: %d\n", slices % friends);
    return 0;
}
▶ Output
Each friend gets: 3
Left over: 2
💡 Is it even or odd?A number is even if number % 2 is 0, and odd if it is 1. You'll use this a lot!

Increment and decrement

example.c
#include <stdio.h>

int main() {
    int steps = 10;
    steps++;     // same as steps = steps + 1
    printf("%d\n", steps);
    steps--;     // same as steps = steps - 1
    steps--;
    printf("%d\n", steps);
    return 0;
}
▶ Output
11
9

3. Assignment operators

= stores a value in a variable. The compound operators are shortcuts that do math and store the result in one step:

OperatorExampleSame as
=x = 5x = 5
+=x += 3x = x + 3
-=x -= 3x = x - 3
*=x *= 3x = x * 3
/=x /= 3x = x / 3
%=x %= 3x = x % 3
example.c
#include <stdio.h>

int main() {
    int points = 10;
    points += 5;     // 15
    points *= 2;     // 30
    points -= 4;     // 26
    points /= 2;     // 13
    printf("Points: %d\n", points);
    return 0;
}
▶ Output
Points: 13

4. Comparison operators

Comparison operators ask a yes/no question. In C, the answer is a number: 1 means true and 0 means false.

OperatorMeaningExampleResult
==equal to5 == 51
!=not equal to5 != 50
>greater than7 > 31
<less than7 < 30
>=greater than or equal to75 >= 751
<=less than or equal to80 <= 750
example.c
#include <stdio.h>

int main() {
    int myGrade = 82;
    int passing = 75;

    printf("Did I pass? %d\n", myGrade >= passing);
    printf("Perfect score? %d\n", myGrade == 100);
    return 0;
}
▶ Output
Did I pass? 1
Perfect score? 0
⚠️ = is not ==One = stores a value (x = 5). Two == compares values (x == 5). Mixing them up is one of the most common mistakes in C!

You'll use comparisons with if…else to make decisions in a later lesson.

5. Logical operators

Logical operators combine two true/false answers:

OperatorNameTrue when…ExampleResult
&&ANDboth sides are true5 > 3 && 2 > 11
||ORat least one side is true5 > 3 || 2 > 91
!NOTthe value is false (it flips the answer)!(5 > 3)0
example.c
#include <stdio.h>

int main() {
    int age = 13;
    int hasID = 1;     // 1 = yes, 0 = no

    // Can join the club if 12 or older AND has an ID
    printf("Can join: %d\n", age >= 12 && hasID);

    // Free entry if younger than 7 OR 60 and older
    printf("Free entry: %d\n", age < 7 || age >= 60);
    return 0;
}
▶ Output
Can join: 1
Free entry: 0

6. Order of operations

Just like in math (MDAS), C does *, / and % before + and -. Use parentheses to choose what goes first:

example.c
#include <stdio.h>

int main() {
    printf("%d\n", 2 + 3 * 4);
    printf("%d\n", (2 + 3) * 4);
    printf("%d\n", 20 - 10 / 5);
    printf("%d\n", (20 - 10) / 5);
    return 0;
}
▶ Output
14
20
18
2

✅ What You Learned

  • Arithmetic: + - * /, % (remainder) and ++ --. int / int cuts off decimals.
  • Assignment: = stores a value. += -= *= /= are shortcuts.
  • Comparison: == != > < >= <= give 1 (true) or 0 (false).
  • Logical: && (both), || (either), ! (not).
  • * / % come before + -. Use parentheses to change the order.
  • Don't mix up = (store) and == (compare)!
