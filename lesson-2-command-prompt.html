⌨️ Command Prompt Basics

Programmers often control the computer by typing commands instead of clicking. In this lesson you'll learn to move between folders in the Command Prompt, then compile and run your C program with gcc.

1. Opening the Command Prompt

The Command Prompt (also called cmd, the terminal, or the console) is a black window where you type commands. Here are three ways to open it:

  1. Run box: press ⊞ Win + R, type cmd, and press Enter.
  2. Start menu: press ⊞ Win, type cmd, and click Command Prompt.
  3. From a folder ⭐: open your folder (like C:\cprog) in File Explorer, click the address bar at the top, type cmd, and press Enter. The Command Prompt opens already inside that folder!

2. Reading the prompt

The text before the blinking cursor is called the prompt. It tells you which folder you are in right now. This is your current directory. (Directory is another word for folder.)

C:Drive
\Users\StudentFolder path
>Type after this
 dirYour command

So C:\Users\Student> means: "You are inside the Student folder, which is inside Users, on drive C:." The backslash \ separates folder names.

3. The most common commands

Type a command and press Enter to run it. Commands are not case-sensitive, so DIR and dir do the same thing.

4. Time-saving tricks

Tab auto-complete

Type the first few letters of a file or folder name, then press Tab. Cmd finishes the name for you, e.g. cd Doc + Tab becomes cd Documents.

↑ ↓ history

Press the Up arrow to bring back the commands you typed before. You don't have to retype gcc ... every time!

"Quotes" for spaces

If a folder name has spaces, put quotes around it: cd "My Programs". Better yet, avoid spaces in your folder names.

Ctrl + C to stop

If a program gets stuck (like a loop that never ends), press Ctrl + C to stop it.

5. Compile and run with gcc

Now let's put it all together using the hello.c file you saved in C:\cprog in Lesson 1.

Step 1: Go to your folder

Command Prompt
C:\Users\Student> cd C:\cprog
C:\cprog>

Step 2: Check that hello.c is there

Command Prompt
C:\cprog> dir
 Directory of C:\cprog

10/19/2026  08:00 PM    <DIR>          .
10/19/2026  08:00 PM    <DIR>          ..
10/19/2026  08:00 PM                88 hello.c
               1 File(s)             88 bytes

Step 3: Compile it

Command Prompt
C:\cprog> gcc hello.c -o hello
C:\cprog>

Let's break that command down:

gccRun the compiler.
hello.cThe C file you want to compile (the input).
-o hello-o means output: name the program hello.exe. If you leave this out, gcc names it a.exe.
💡 No message = good news! If gcc prints nothing and just shows the prompt again, your program compiled with no errors. Type dir and you'll see a new file: hello.exe.

Step 4: Run it

Command Prompt
C:\cprog> hello
Hello, World!
C:\cprog>

🎉 You just compiled and ran your first C program!

The programmer's loop

EditChange code in
Sublime Text

Compilegcc hello.c -o hello

Every time you change your code, you must save and compile again. Otherwise you'll keep running the old version! Use the ↑ arrow to repeat the gcc command quickly.

💡 Turn on warnings Add -Wall to see helpful warnings about code that might be wrong:
gcc -Wall hello.c -o hello
💡 Using PowerShell or Windows Terminal? Everything above works there too, except that to run your program you type .\hello instead of just hello.

6. Common errors and fixes

You see…It means…Fix
'gcc' is not recognized…Windows can't find gcc.Check your PATH from Lesson 1, then open a new cmd window.
No such file or directorygcc can't find your .c file in this folder.Use dir to look. Are you in the right folder? Is it really named hello.c (not hello.c.txt)?
The system cannot find the path specified.The folder you typed after cd doesn't exist.Check the spelling. Use Tab to auto-complete.
hello.c:4:5: error: …There's a mistake in your code on line 4, column 5.Go to that line in Sublime. Look for a missing ; or " or }.
Old output still showsYou didn't save or recompile.Ctrl+S, then run gcc again.
Permission denied (ld.exe)The old hello.exe is still running.Close the program's window (or press Ctrl+C), then compile again.
