📐 C Syntax

Syntax means the rules for how code must be written, like grammar and punctuation in English. If you break a rule, the compiler can't understand your program.
In this lesson
  1. Hello World, line by line
  2. Every statement ends with ;
  3. Spaces and new lines
  4. Curly braces { } come in pairs
  5. C is case-sensitive
  6. Quiz

1. Hello World, line by line

Let's look closely at the Hello World program and what each line does.

hello.c
#include <stdio.h>

int main() {
    printf("Hello World!\n");
    return 0;
}
▶ Output
Hello World!
LineCodeWhat it means
1#include <stdio.h>Brings in the standard input/output header file, so we can use printf(). Almost every program has this line.
2(blank)Blank lines are ignored. They just make code easier to read.
3int main() {main() is where the program starts. The code inside its braces { } runs.
4printf("Hello World!\n");Prints text on the screen. (\n moves to a new line. More in Lesson 5!)
5return 0;Ends main() and tells the computer "finished successfully."
6}Closes main(). Never forget the closing brace!

2. Every statement ends with ;

A statement is one instruction, like a sentence. In English a sentence ends with a period. In C, a statement ends with a semicolon ;.

snippet
printf("Hi!\n");   // statement 1
return 0;          // statement 2

If you forget a semicolon, gcc stops and tells you where it expected one:

example.c
#include <stdio.h>

int main() {
    printf("Hello World!\n")
    return 0;
}
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:4:29: error: expected ';' before 'return'
    4 |     printf("Hello World!\n")
      |                             ^
💡 Read the error message!The 4:29 means line 4, column 29. gcc even shows a ^ pointing at the spot and suggests the missing ;. gcc says "before 'return'" because it only notices the problem when it reaches the next line.
⚠️ No semicolon hereLines that start with # (like #include) and lines that end with { or } do not get a semicolon.

3. Spaces and new lines

The compiler ignores extra spaces, tabs and blank lines. This program works exactly the same, even squeezed onto one line:

example.c
#include <stdio.h>
int main(){printf("Hello World!\n");return 0;}
▶ Output
Hello World!

It works, but it's hard to read! Programmers write one statement per line and indent (push in with Tab or 4 spaces) the code inside braces, so you can see at a glance what belongs inside main().

4. Curly braces { } come in pairs

Curly braces group code together into a block. Every opening { must have a closing }. Here's what happens when one is missing:

example.c
#include <stdio.h>

int main() {
    printf("Hello World!\n");
    return 0;
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:5:5: error: expected declaration or statement at end of input
    5 |     return 0;
      |     ^~~~~~
💡 Sublime Text helpsClick right after a { and Sublime underlines its matching }. If nothing lights up, a brace is missing!

5. C is case-sensitive

Uppercase and lowercase letters are different in C. printf, Printf and PRINTF are three different names, and only the lowercase one exists.

example.c
#include <stdio.h>

int main() {
    Printf("Hello World!\n");
    return 0;
}
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:4:5: error: implicit declaration of function 'Printf'; did you mean 'printf'? [-Werror=implicit-function-declaration]
    4 |     Printf("Hello World!\n");
      |     ^~~~~~

Keywords and built-in functions such as int, main, return and printf are always written in lowercase.

6. Quiz 🎯

Try It! On a real computerType the Hello World program without looking. Compile it. Then make mistakes on purpose, one at a time: remove a ;, change printf to Printf, and delete the last }. Read each error message gcc gives you, then fix it.

✅ What You Learned

  • Syntax = the rules for writing code.
  • Every statement ends with ; (but not #include lines or braces).
  • Code inside { } is a block. Every { needs a }.
  • Spaces and blank lines are ignored, so use them to make code readable.
  • C is case-sensitive: write printf and main in lowercase.
  • gcc errors show line:column. Read them!
