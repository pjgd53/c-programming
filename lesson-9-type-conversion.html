🔄 C Type Conversion

Sometimes a value needs to change from one data type to another, like an int to a float. This is called type conversion, and it explains some surprising results!
In this lesson
  1. The problem: 5 ÷ 2 = 2?!
  2. Implicit conversion (automatic)
  3. Explicit conversion (casting)
  4. Side by side: where you put the cast matters
  5. Real-life example: quiz percentage

1. The problem: 5 ÷ 2 = 2?!

Try dividing two whole numbers:

example.c
#include <stdio.h>

int main() {
    int x = 5;
    int y = 2;
    int result = x / y;

    printf("%d\n", result);
    return 0;
}
▶ Output
2

Why not 2.5? When you divide an int by an int, C gives an int answer. The decimal part is simply chopped off (not rounded). This is called integer division. To get 2.5, we need type conversion.

There are two kinds: implicit (C does it automatically) and explicit (you do it yourself).

2. Implicit conversion (automatic)

When you store a value in a variable of a different type, C converts it automatically.

int → float: safe

example.c
#include <stdio.h>

int main() {
    float myFloat = 9;      // 9 becomes 9.0
    printf("%f\n", myFloat);
    return 0;
}
▶ Output
9.000000

float → int: you lose the decimals!

example.c
#include <stdio.h>

int main() {
    int myInt = 9.99;       // .99 is chopped off
    printf("%d\n", myInt);
    return 0;
}
▶ Output
9
9.99 becomes 9, not 10. Conversion to int cuts off the decimals. It doesn't round.

The sneaky one

example.c
#include <stdio.h>

int main() {
    float result = 5 / 2;
    printf("%f\n", result);
    return 0;
}
▶ Output
2.000000

Even though result is a float, 5 / 2 is calculated first as integer division (= 2). Only then is 2 converted to 2.000000. The .5 was already lost.

3. Explicit conversion (casting)

To convert a value yourself, write the new type in parentheses in front of it. This is called casting:

example.c
#include <stdio.h>

int main() {
    float result = (float) 5 / 2;
    printf("%f\n", result);
    return 0;
}
▶ Output
2.500000

It works with variables too, which is what you'll usually need:

example.c
#include <stdio.h>

int main() {
    int num1 = 5;
    int num2 = 2;
    float result = (float) num1 / num2;

    printf("%f\n", result);
    printf("%.1f\n", result);
    return 0;
}
▶ Output
2.500000
2.5
Use %.1f to hide the extra zeros.
💡 Only one needs to be a floatIf either number in a division is a float or double, C does decimal division. That's why casting just num1 is enough.

4. Side by side: where you put the cast matters

ExpressionResultWhy
5 / 22int ÷ int: the decimal part is cut off.
5.0 / 22.500000One number has a decimal, so C does decimal division.
(float) 5 / 22.500000Cast first: 5 becomes 5.0, then it divides.
(float) (5 / 2)2.000000Divide first: 5 / 2 is already 2 before the cast. Too late!
All results above are real output from gcc.

5. Real-life example: quiz percentage

Ana got 43 out of 50 on a quiz. What's her percentage?

example.c
#include <stdio.h>

int main() {
    int score = 43;
    int totalItems = 50;

    // WRONG: integer division (43 / 50 = 0)
    int wrong = score / totalItems * 100;

    // RIGHT: cast to float first
    float percent = (float) score / totalItems * 100;

    printf("Wrong: %d%%\n", wrong);
    printf("Right: %.2f%%\n", percent);
    return 0;
}
▶ Output
Wrong: 0%
Right: 86.00%

Average of grades

example.c
#include <stdio.h>

int main() {
    int math = 90, science = 87, english = 92;
    int sum = math + science + english;
    float average = (float) sum / 3;

    printf("Sum: %d\n", sum);
    printf("Average: %.2f\n", average);
    return 0;
}
▶ Output
Sum: 269
Average: 89.67

6. Quiz 🎯

Try It! On a real computerWrite a program that stores your scores in 4 quizzes as int variables, and the total number of items in each quiz. Calculate and print: the sum, the average (with 2 decimals) and your percentage. Try it first without casting, see the wrong answer, then fix it with (float).

✅ What You Learned

  • Type conversion changes a value from one type to another.
  • int / int = integer division, so the decimals are cut off (5 / 2 = 2).
  • Implicit: C converts automatically. float → int loses the decimals (it doesn't round).
  • Explicit (casting): (float) num1 / num2 gives a decimal answer.
  • Cast before dividing, not after: (float)(5 / 2) is still 2.
