🖨️ C Output (Printing Text)

Programs need to show results. In C, we use the printf() function to print text and values on the screen.
In this lesson
  1. The printf() function
  2. Text needs double quotes
  3. Many printf() calls
  4. New lines with \n
  5. Escape sequences
  6. Quiz

1. The printf() function

printf() (say: "print-eff", for print formatted) displays whatever you put between its double quotes.

example.c
#include <stdio.h>

int main() {
    printf("Welcome to The Yellow Woods Academy!\n");
    return 0;
}
▶ Output
Welcome to The Yellow Woods Academy!

2. Text needs double quotes

The text you want to print must start and end with double quotes " ". This kind of text is called a string.

example.c
#include <stdio.h>

int main() {
    printf(This will not work);
    return 0;
}
❌ Compiler says
C:\cprog> gcc example.c -o example
example.c:4:12: error: 'This' undeclared (first use in this function)
    4 |     printf(This will not work);
      |            ^~~~
⚠️ Single quotes won't work either'Hello' is wrong for text. In C, single quotes are only for one character, like 'A'. You'll learn more in Lesson 7.

3. Many printf() calls

You can use as many printf() statements as you want. But watch what happens without \n:

example.c
#include <stdio.h>

int main() {
    printf("Hello World!");
    printf("I am learning C.");
    printf("And it is awesome!");
    return 0;
}
▶ Output
Hello World!I am learning C.And it is awesome!

Everything prints on one line! printf() doesn't move to the next line by itself. You have to tell it to.

4. New lines with \n

\n is the newline character. It works like pressing Enter inside your text: the cursor moves to the start of the next line.

example.c
#include <stdio.h>

int main() {
    printf("Hello World!\n");
    printf("I am learning C.\n");
    printf("And it is awesome!\n");
    return 0;
}
▶ Output
Hello World!
I am learning C.
And it is awesome!

You can put \n anywhere inside the quotes, even several in one printf(). Two \n in a row make a blank line:

example.c
#include <stdio.h>

int main() {
    printf("Line 1\nLine 2\n\nLine 4 (after a blank line)\n");
    return 0;
}
▶ Output
Line 1
Line 2

Line 4 (after a blank line)

5. Escape sequences

\n is one of several escape sequences: a backslash \ followed by a letter or symbol, used for characters you can't type directly inside quotes.

Escape sequenceWhat it printsExample
\nNew lineprintf("Hi\nThere");
\tTab (a big space, used to line up columns)printf("Name\tScore");
\"A double quote "printf("She said \"Hi\"");
\\A backslash \printf("C:\\cprog");
%%A percent sign % (special for printf)printf("100%%");
example.c
#include <stdio.h>

int main() {
    printf("Name\tMath\tScience\n");
    printf("Ana\t95\t90\n");
    printf("Ben\t88\t93\n");
    printf("\n");
    printf("Teacher said: \"Great job!\"\n");
    printf("Saved in C:\\cprog\n");
    printf("Attendance: 100%%\n");
    return 0;
}
▶ Output
Name	Math	Science
Ana	95	90
Ben	88	93

Teacher said: "Great job!"
Saved in C:\cprog
Attendance: 100%
Tabs line up the columns, like a table.

6. Quiz 🎯

Try It! On a real computerMake a name card program that prints your name, grade and section, favorite subject and a quote in double quotes on separate lines. Then add a small table of 3 subjects and your target scores using \t to line up the columns.

✅ What You Learned

  • printf("...") prints the text inside the double quotes.
  • Text in double quotes is called a string.
  • printf() does not go to a new line by itself, so use \n.
  • Escape sequences: \n new line, \t tab, \" quote, \\ backslash, and %% for a percent sign.
